# Guide utilisateur — GameConnect

## 1. Créer un compte

1. Aller sur `http://localhost:5173`
2. Cliquer sur **S'inscrire**
3. **Étape 1** : Renseigner email, pseudo (3-50 caractères), mot de passe (≥8 chars, 1 lettre + 1 chiffre)
4. **Étape 2** : Compléter les informations optionnelles : région, date de naissance, pseudo Discord, biographie, niveau global, ce que vous recherchez
5. Cliquer sur **Créer mon compte**

> Le mot de passe doit contenir au moins 8 caractères, une lettre et un chiffre.

---

## 2. Se connecter

1. Cliquer sur **Se connecter**
2. Saisir votre email et mot de passe
3. Cliquer sur **Se connecter**

La session dure **7 jours**. Après expiration, vous serez automatiquement redirigé vers la page de connexion.

---

## 3. Compléter son profil

1. Cliquer sur votre **avatar** en haut à droite → **Profil**
2. Cliquer sur **Modifier** (icône crayon)
3. Modifier les informations souhaitées :
   - **Avatar** : cliquer sur l'avatar → sélectionner dans la galerie ou uploader une image
   - **Bannière** : même procédure
   - **Bio** : maximum 1000 caractères
   - **Réseaux gaming** : Discord, Steam, Twitch, Riot ID
   - **Visibilité** : Public / Amis / Privé
4. Cliquer sur **Sauvegarder**

---

## 4. Gérer sa bibliothèque de jeux

### Ajouter un jeu

1. Page **Profil** → section "Mes jeux" → cliquer **+ Ajouter**
2. Sélectionner un jeu dans la liste
3. Renseigner : niveau (Débutant/Intermédiaire/Avancé/Expert), rang, heures jouées, cocher "favori" si souhaité
4. Cliquer **Ajouter**

### Modifier un jeu

1. Sur la carte du jeu → cliquer l'icône **crayon ✏️**
2. La modal s'ouvre avec les valeurs actuelles
3. Modifier les champs → cliquer **Sauvegarder**

### Supprimer un jeu

1. Sur la carte du jeu → cliquer l'icône **corbeille 🗑**
2. Le jeu est retiré de votre profil

---

## 5. Trouver des partenaires

1. Cliquer sur **Matching** dans la navigation
2. Onglet **Découvrir** → cliquer **Trouver des partenaires**
3. Le système propose des joueurs triés par **score de compatibilité** (0-100%) basé sur :
   - Les jeux en commun
   - La compatibilité des niveaux
   - La région et le fuseau horaire
   - Le style de jeu recherché
4. Pour chaque profil :
   - **✓ Accepter** : commence une mise en relation (vous pouvez vous écrire)
   - **✕ Refuser** : rejette la proposition

5. Onglet **Mes matchs** : voir tous les joueurs avec qui vous avez un match accepté

---

## 6. Envoyer et gérer des messages

> Vous ne pouvez écrire qu'aux joueurs avec qui vous avez un **match accepté**.

### Écrire un message

1. Cliquer sur **Messages** dans la navigation
2. Sélectionner une conversation dans la liste de gauche
3. Saisir votre message dans le champ en bas (max 1000 caractères)
4. Appuyer sur **Entrée** ou cliquer le bouton envoi ▶

### Supprimer un message

1. Survoler votre message avec la souris → l'icône **🗑** apparaît à gauche
2. Cliquer sur **🗑**
3. Le message disparaît de la conversation

> **Important** : La suppression est définitive dans l'interface, mais le message est conservé dans la base de données (soft-delete). L'autre joueur ne peut plus le voir.

### Sur mobile

Sur petit écran, la liste des conversations et le fil de messages s'affichent en plein écran alternativement. Utiliser le bouton **◀** pour revenir à la liste des conversations.

---

## 7. Gérer ses notifications

L'icône cloche 🔔 dans la navigation affiche le nombre de notifications non lues.

**Types de notifications** :
- 🎯 **Nouveau match** : un joueur vous a été proposé
- ✅ **Match accepté** : quelqu'un a accepté votre mise en relation
- 💬 **Nouveau message** : vous avez reçu un message

**Actions disponibles** :
- Cliquer sur une notification → la marquer comme lue
- **Tout marquer comme lu** → vide le compteur
- **Supprimer** une notification individuelle

---

## 8. Rechercher des joueurs et jeux

La barre de recherche (loupe en haut à droite) propose de l'autocomplétion :

- **Joueurs** : recherche par pseudo ou biographie
- **Jeux** : recherche par nom de jeu

Filtres disponibles : jeu, niveau, région, type de recherche.

> Les profils en mode **Privé** n'apparaissent pas dans les résultats de recherche.

---

## 9. Changer le thème

Cliquer sur l'icône ☀️/🌙 dans la navigation pour basculer entre le thème sombre et clair. Le choix est sauvegardé automatiquement.

---

## 10. Se déconnecter

Cliquer sur votre avatar → **Se déconnecter**. Votre session sera fermée et vous serez redirigé vers la page d'accueil.
